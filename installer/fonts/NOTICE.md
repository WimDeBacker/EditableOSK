# SchoolKX_New (font)

`SchoolKX_new.ttf` is the font used by `azertycolor.kbl` (the coloured school layout). The installer puts it in the Windows Fonts folder
(`installer/setup.iss`, `[Files]`), and never removes it again when the program is uninstalled.

- **Source:** https://github.com/kostex/SchoolKX_New (author: kostex)
- **Terms** (from that project's README, checked 2026-10-09; it has no licence file): the author says to do whatever you want with the
  fonts, except claiming them as yours. Commercial use is free; the author asks commercial users to get in touch or show their product, and to
  refer to the project site. Redistribution and bundling in an installer are not mentioned separately.
- **What this project does with it:** it keeps the author's file unchanged, names the author and the source here and in `README.md`, and
  does not claim the font. Anyone who uses this program commercially should read the author's README and follow its request.
- Internal family name: `SchoolKX_New` (this is the name `FontInstall` in `setup.iss` must use).
